# Quality & Risk Register: ProDoc Word Processor

| Risk ID | Category | Description | Likelihood | Impact | Detection Mechanism | Mitigation Strategy | Status |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **RSK-001** | Runtime Crash | Missing React hook imports causing runtime `ReferenceError` when lazy-loading tabs. | Medium | Critical | Automated build, eslint, and Vitest component render tests. | Strict ESLint hook rules and unit tests rendering each ribbon tool independently. | **Mitigated** (BUG-001 fixed) |
| **RSK-002** | Schema Drift | Deserializing older `.docjson` v1/v2 files without stable node IDs or missing schemaVersion stamp. | High | High | Bidirectional schema migration test suite (`tests/unit/documentModel.test.ts`). | Explicit schema migration registry with automatic schemaVersion stamping in `htmlToJSONDocument`. | **Mitigated** (BUG-002 fixed) |
| **RSK-003** | Data Loss | Unhandled localStorage quota exhaustion during large document auto-save. | Medium | High | Integration tests mocking storage exceptions (`tests/integration/persistence.test.ts`). | Try/catch isolation with user notifications and fallback in-memory caching. | **Mitigated** |
| **RSK-004** | Security / XSS | Malicious `<script>`, `onerror`, or `javascript:` URLs injected via pasted HTML or imported files. | Medium | Critical | Adversarial fuzz test suite (`tests/adversarial/unicodeAndFuzz.test.ts`). | DOMParser sanitization neutralizing executable tags and handlers before injecting into editor AST. | **Mitigated** |
| **RSK-005** | Unicode Corruption | Complex multi-grapheme scripts (Bangla matras, Arabic RTL, joined emojis, zero-width characters) corrupted during conversion. | Medium | High | Property-based fuzz tests using `fast-check` (`tests/adversarial/unicodeAndFuzz.test.ts`). | Strict code-point and grapheme cluster preservation; avoiding index-based string slicing. | **Mitigated** |
| **RSK-006** | State Inconsistency | Double-tap or rapid pinch-to-zoom causes document scroll position jumping or native browser zoom collision. | Medium | Medium | Non-passive touch listener architecture in `useTouchZoom.tsx`. | Anchored focal midpoint compensation and cancellation of default browser touch pinch events. | **Mitigated** |
| **RSK-007** | Format Degradation | Round-trip conversion (HTML ↔ JSONDocumentModel ↔ HTML) drops tables, marks, or headers. | High | High | Semantic round-trip test suite (`tests/integration/roundtrip.test.ts`). | Structured serializers preserving table matrix invariants and text run styles. | **Mitigated** |
| **RSK-008** | UX / Interaction | Gesture library drag handler intercepting single-finger typing, tap-to-focus, or text selection. | High | High | Manual mobile interaction testing & touch-event unit tests. | Strict `touches === 2` multi-touch guard on drag pan, leaving single-touch 100% unhindered for document editing. | **Mitigated** |
